Q: Is this going to be for quest?

Currently we are not focusing on quest, we may work towards quest in the future but as of right now, it's PCVR only.

Q: How can I install the game?

Currently we don't have a public version out yet, be sure to look out in ‼️︱announcements for the meantime.

Q: Will there be cosmetics?

At this point cosmetics are something that is a bit risky for us due to the legalities surrounding it. So the current answer is no, but not completely no in the future if anything changes.

Q: How will modding work?

We'd like to have a mod architecture set up that allows for user generated content (mods, not cheats) on a per server basis where each server owner is able to add/configure their own specific set of specific mods for that server.

Q: How will servers work?

We can't explain exact specifics of how our servers will be working, but we can tell you:

  • We will host servers of the game.
  • The game version will be the most latest version of the game.
  • You will be able to connect with a vanilla install using a simple launch argument or maybe a mod.
  • We will be working on a modding framework and an anti-cheat system all integrated together to allow for a pure vanilla ATT experience and a modded ATT experience without any cheaters leaking through the cracks.

Q: Why is it taking so long for any updates on this?

Behind the scenes a lot of stuff is going on and currently this project is in a legal gray area so until Poi says otherwise none of us Developers/Devs nor Poi can really give out too much about how the project is going.

Q: When will Moderator Applications be open?

Currently until Poi/The Project Lead says so we will not be accepting Moderator Applications but likely if Moderator Applications open up there will be an announcement in ‼️︱announcements.

Q: Can I become a Dev/Developer?

No. Unless Poi/The Project Lead picks you out there will likely not be any Developer Application nor will you become a Dev. Not trying to be harsh, just the reality of things (also, asking him won't increase your chances, it will likely probably just lower your chances).
